## Журнал реализованных фич

### 2026-05-28 — RUN-слой (`b37a752`, ветка main)
- `tools/matsim_run.py`: запуск MATSim через `java -cp <jar> <main-class>` (или `-jar`).
- Огромный stdout MATSim → лог-файл; агенту возвращается компактный JSON
  (status, exit_code, duration, log path, опц. метрики через `--summarize`).
- Рассчитан на фоновый запуск (Claude Code `run_in_background`) для длинных прогонов.
- Поддержка `--dry-run`, `--iterations`/`--output` как штатные `--config:` оверрайды
  (сам config.xml не меняется), `--threads`, `--timeout`, `log_tail` при ошибке.
- **Проверено на реальном Shamalgan** (1 итерация, ~25 c): exit 0 + распарсенные метрики.
- Найдено и исправлено в тесте 2 бага:
  - относительный `--output` теперь резолвится относительно `--cwd`;
  - лог пишется СНАРУЖИ output-папки (MATSim удаляет её при старте → повторный
    прогон падал на Windows из-за открытого хэндла). Повторный прогон теперь проходит.

### 2026-05-28 — READ-ONLY слой + архитектура (`6cc47ac`, ветка main)
- `tools/matsim_metrics.py`: парсер штатных `scorestats/modestats/traveldistancestats.csv`
  (`;`-разделитель, регистронезависимая колонка итерации) → компактный JSON.
- `tools/matsim_summary.py`: потоковый разбор `network.xml`/`plans.xml` (вкл. `.gz`)
  через iterparse → агрегаты; предупреждает о freespeed > 50 м/с (вероятно км/ч).
- `docs/ARCHITECTURE.md`: план-синтез на 4 слоя. Ключевое упрощение: Java-хук для
  метрик НЕ нужен — MATSim сам пишет CSV.
- **Проверено на реальном Shamalgan** (30 481 агент, сеть 2991 звено).

### 2026-05-15 — Начальный каркас (`b103807`, ветка main)
- Skill `transport-modeling`: ~60 правил из 4 источников [M]/[G]/[RK]/[SP] с привязкой
  к страницам. Критические правила в `SKILL.md`, полный свод в `references/rules.md`,
  карта тема→глава в `references/sources.md`. Правило честности: не выдумывать значения.
- Hook `validate_matsim.py`: PreToolUse блокирует Edit/Write по MATSim XML при нарушениях
  (flowCap == storageCap, обязательный endTime, freespeed sanity-check). Не-MATSim файлы
  пропускает молча. Тест-раннер `tests/test_hooks.py` — 4/4.
- Инсталл-скрипты (Windows PowerShell + macOS/Linux), MIT-лицензия.

## Известные ограничения / заметки

- MODIFY-слой ещё не реализован — модель пока меняется вручную (под защитой hook).
- MCP-обёртки нет: инструменты вызываются как CLI через Bash. MCP добавим когда CLI
  докажет пользу на практике.
- Контур обратной связи опирается на штатные output-CSV MATSim. Если проект использует
  нестандартные имена/форматы статистики — парсеры нужно будет адаптировать.
