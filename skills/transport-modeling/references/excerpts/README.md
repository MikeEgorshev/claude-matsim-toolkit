# Папка выжимок из источников

Сюда клади выжимки из источников (главы из книг, статьи закона) когда нужно копнуть глубже.

**Соглашение по именам:** `<тег-источника>-<тема>.md`

Примеры:
- `M-ch5-subtour-mode-choice.md` — глава 5 MATSim книги про SubtourModeChoice
- `G-gravity-model.md` — глава из Горева про гравитационную модель
- `SP-table5-design-speeds.md` — таблица 5 из СП РК

Теги источников: [M], [G], [RK], [SP] — см. `../sources.md`.

Эти файлы НЕ коммитятся в git (см. `.gitignore` в корне скилла) — это твои локальные подсказки.
