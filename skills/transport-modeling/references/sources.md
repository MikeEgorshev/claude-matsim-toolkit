# Указатель источников — где искать ответы глубже

Когда `references/rules.md` не даёт ответа, используй эту карту чтобы:
1. Указать пользователю конкретный источник и раздел
2. Попросить пользователя положить выжимку нужной главы в `references/excerpts/`
3. Если выжимка уже лежит — прочитать её через Read tool

## Что делать когда нужный топик не покрыт ни rules.md, ни этой картой

1. Скажи пользователю прямо: «у меня нет верифицированного правила по этому вопросу»
2. Предположи в каком из четырёх источников ответ скорее всего есть (по тематике)
3. Попроси пользователя дочитать раздел и положить выжимку в `references/excerpts/<source>-<topic>.md`
4. После этого можешь читать выжимку через Read tool и работать с проверенной информацией

**Не выдумывай конкретные числовые значения.** Размытое «обычно около...» в транспортном моделировании часто хуже честного «не знаю, посмотри в книге N на стр. M».
